# Reproducibility and evidence boundaries

This guide explains which parts of the HCC MHC-II peptide prioritisation study can be reproduced from the repository and which depend on original inputs kept in a separate research workspace. Reproducing a ranking is not the same as validating a peptide biologically: no mutant-specific CD4 response, defined HLA-II restriction, natural tumour presentation or vaccine efficacy was demonstrated.

## 1. Scope and computational environment

The study examined **TP53 R249S** and **CTNNB1 S45P** using hypothetical **HLA-DRB1*01:01** and **HLA-DRB1*04:01** contexts. The 216 WT/MUT–HLA paired comparisons derive from overlapping 15-, 18- and 21-amino-acid windows around **two mutations**; they are not 216 independent mutations, patients, or confirmed neoantigens. The frozen input to Phase 2 was derived from **432 NetMHCIIpan-4.3k prediction records** (WT and MUT), originally obtained through web runs using PEPTIDE input, EL+BA output and context encoding off.

Python requirements for the included Phase 2 workflow are recorded in [`requirements.txt`](../requirements.txt). Phase 2 was rerun successfully in the original Mac Python environment. The remaining stages have not all been tested from a clean checkout. NetMHCIIpan web-service access and its original prediction files are separate from the Python workflow.

## 3. Reproduce Phase 2 without changing frozen files

Run these commands from the repository root in a Python environment with the dependencies in `requirements.txt` installed:

```bash
python -m pip install -r requirements.txt
CHECK_DIR=$(mktemp -d)
python phase2_prioritise.py --out "$CHECK_DIR"
cmp results/phase2/phase2_all_216_ranked.csv "$CHECK_DIR/phase2_all_216_ranked.csv"
echo "Comparison exit code: $?"
```

On **13 November 2026**, the original Mac checkout returned `PHASE 2 DECISION ANALYSIS PASSED` and `Comparison exit code: 0`. Here, `cmp` checks whether the new ranking file matches the recorded output byte for byte; the temporary directory keeps the frozen result untouched. If the files differ or a dependency is missing, investigate rather than altering the recorded input or rules. The commands use the standard macOS/Linux utilities `cmp` and `mktemp` and may need adapting elsewhere.

## 5. How to interpret the outputs

**Predictions and measurements.** Lower NetMHCIIpan BA/EL percentile ranks indicate more favourable predictions for their respective model endpoints. The study's `delta_BA = WT BA %Rank − MUT BA %Rank`; a positive value denotes a more favourable *predicted* MUT rank, not a measured affinity change, a confirmed binding event, or CD4 immunogenicity. Predicted 9-mer core and core-offset shifts are model outputs, not observed HLA-bound registers.

**Comparing the rules.** A, B and C use different selection objectives. Their Top-10 overlap and diversity measures do not establish that one strategy discovers better immunogenic neoantigens. In particular, counts of distinct **(gene, HLA, predicted MUT 9-mer core) groups** must not be presented as counts of distinct 9-mer core sequences. The study was expanded from an initial pilot and is not a prospectively blinded performance evaluation.

**Published assay records.** Six IEDB T-cell assay annotations matched three WT control sequences studied in a separate TP53 R248Q/R248W context. They do not validate the TP53 R249S mutant, establish mutation-specific CD4 recognition, or confirm a specific HLA-II restriction for the candidates in this case study. The CEDAR overlap does not constitute an independent replication of those same assay records.

**Historical binding comparison.** The Repáraz HCC panel provides experimental binding classifications for 13 peptides. It was preselected using earlier computational predictions, is small and may not be independent of predictor development. The published experimental readout is not equivalent to human CD4 recognition or natural tumour presentation. Source-level gene/mutation notation discrepancies and HLA-suballele ambiguity, including one supplementary DRB1*01:02 context versus the DRB1*01:01 computational comparison, remain interpretation limits. These results are descriptive, not an unbiased external benchmark.

**Proposed experiments.** The Phase 4 plan separates biochemical binding, peptide-pulsed CD4 recognition, allele restriction and processing of full-length antigen. The evidence gates are hypotheses; neither an HLA-DR blockade alone nor a model-predicted binding score independently proves native tumour-cell peptide presentation or vaccine efficacy.

## 6. Public-release boundaries

This repository does not include the original article PDFs, supplements, raw NetMHCIIpan outputs or selected IEDB/CEDAR downloads. These are retained separately pending provenance, redistribution-rights and disclosure checks. It also excludes virtual environments, caches, temporary archives and local workspace-specific files. Public code may refer to excluded `raw/` files; those scripts are kept as research-method records and **will not run end-to-end from the reduced release without the missing inputs**. No credentials, patient-identifiable information or materials lacking redistribution clearance should be committed.

Before making the repository public, check the rendered links and figures, review source attribution and redistribution permissions, and inspect the staged Git files. The recorded hashes and successful Phase 2 rerun are computational integrity checks, not evidence of licensing clearance or biological validation.
